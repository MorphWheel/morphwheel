## תקציר

- **גלגלת של 8 משבצות בעלות מיקום קבוע**, כדי שהיד תזכור איפה כל פורמט נמצא. במרכז יש hub, שהוא אזור ביטול וגם אזור מידע.
- **משבצת "More"** פותחת קשת חיצונית עם plugins.
- **החלון יחיד ושקוף, וגדול מהדיסקית.** טבעת "תופסת" בלתי נראית סביב הדיסקית מבטלת שחרור שנפל לידה.
- **הגלגלת "דביקה":** היא נשארת פתוחה גם כשמשחררים את Shift. כדי לחזור לגרירה רגילה, מתרחקים מהגלגלת.
- **תהליך העיבוד לא מוצג בגלגלת,** כי היא נעלמת ב-drop. הוא מוצג ב-toast מותאם בפינה ימנית-תחתונה, עם התקדמות, ‏"Show in folder" ו-Undo.
- **Light ו-Dark לפי המערכת.** צבע ההדגשה הוא ה-accent של Windows. הצבעים ומשכי התנועה לקוחים מ-WinUI.
- **אין blur ב-MVP.** במקומו, משטח אטום ב-92%.
- **הכול עובד גם בלי אנימציות.** במחשב הזה (סשן RDP) האנימציות של Windows כבויות כרגע. ✅
- **7 החלטות עיצוב מחכות לך ב-§9.** שתיים מהן (U1 ו-U2) **משנות כללים שאושרו בשלב 2**, ובסך הכול שלושה כללים. הן מסומנות.

## 2. הגלגלת: מבנה, גדלים ומשבצות

### 2.1 גאומטריה (בגודל M, בפיקסלים לוגיים)

```
 radius:  0 ────── 36 ── 40 ─────────────────── 118 ── 124 ──────────── 170 ────── 190
          │  HUB      │gap│   SLOT RING (8 slots)   │gap│  MORE ARC (on demand)│ CATCH HALO │
          │ cancel +  │   │ labels at r≈79          │   │  up to 6 items       │ invisible, │
          │ info      │   │ 45° per slot, 3° gaps   │   │                      │ alpha ≥ 1  │
 window: 380 × 380 logical px (fixed; sized for the largest state)
```

| | S | **M (ברירת מחדל)** | L |
|---|---|---|---|
| קנה מידה | 0.85 | 1.0 | 1.2 |
| קוטר הדיסקית (טבעת המשבצות) | 200 | **236** | 284 |
| רוחב קשת בגובה התוויות (45°) | ≈ 53 | ≈ 62 | ≈ 74 |
| חלון | 323 | 380 | 456 |

- **לשם השוואה:** ב-spike הדיסקית הייתה בקוטר 276 ובחלון של 300. זה בין M ל-L. **זו שאלה אליך (U4).**
- **DPI:** כל הגדלים לוגיים, ו-Qt ממיר אותם לפיקסלים פיזיים (per-monitor-v2 ✅; במחשב הזה ה-DPR הוא 1.5).
- **ריבוי מסכים:** הגלגלת מוצגת במסך שבו נמצא הסמן, והדיסקית לעולם לא חוצה שני מסכים.
- **הצמדה לקצה:** ההצמדה נקבעת לפי **הדיסקית** (רדיוס 118 ב-M), לא לפי החלון כולו. הטבעת התופסת יכולה לחרוג מהמסך בלי נזק. כשהדיסקית מוזזת, חל כלל החימוש (U7).
- **קשת More בקצה:** אם הכיוון NW נחתך בקצה המסך, הקשת מסתובבת פנימה, לכיוון מרכז המסך.

### 2.2 מפת המשבצות לתמונות

המשבצות קבועות, עם כיוון השעון מלמעלה:

```
                              JPG
                    More       │       PNG
                     ⋯   ╲     │     ╱
                           ╲   │   ╱
              ICO ──────────( HUB )────────── WebP
                           ╱   │   ╲
                         ╱     │     ╲
                    PDF        │       AVIF
                           Compress
```

| כיוון | משבצת | הערה |
|---|---|---|
| N | **JPG** | היעד הנפוץ ביותר, למעלה |
| NE | **PNG** | |
| E | **WebP** | |
| SE | **AVIF** | |
| S | **Compress** | הקיצור לזכירה: "למטה = קטן יותר". זמין לקלט JPG, ‏PNG, ‏WebP ו-AVIF. ל-HEIC, ‏BMP, ‏TIFF ו-GIF המשבצת מושבתת, וה-hub מסביר: "Convert first". **אם הפלט לא קטן מהמקור,** הוא נמחק ומוצג toast של "Already compact" (§5). ב-PNG אין משמעות ל"איכות", ולכן ההגדרה של דחיסת PNG (שינוי גודל, אופטימיזציה, צמצום פלטה) תיקבע ב-M1. |
| SW | **PDF** | |
| W | **ICO** | |
| NW | **More** | פותח את הקשת החיצונית (§2.3) |

- **⚠️ הכלל המלא למשבצת מושבתת (U2), שמשנה כללים שאושרו בשלב 2:**
  - **(א) כל הקבצים יידלגו.** משבצת מושבתת אם כל הקבצים הנגררים כבר בפורמט שלה. בגרירה מסוג אחד היא מסומנת `source`. במקום להיעלם, היא נשארת במקומה, וכך כל פורמט נמצא תמיד באותו מקום.
  - **(ב) קובץ שלא יכול להיות מומר.** משבצת מושבתת גם אם יש קובץ שלא יכול להיות מומר לפורמט שלה. ה-hub מסביר למה.
  - **(ג) בגרירה מעורבת** (למשל PNG ו-JPG), משבצת JPG **זמינה.** קבצי ה-JPG מדולגים, וה-toast מדווח "1 skipped — already JPG". זה במקום חיתוך שמשבית את המשבצת.
- **v0.2 (וידאו ואודיו):** לכל סוג מדיה תהיה מפה קבועה משלו. כשמגיעים סוגים שונים של מדיה יחד, אין פורמט משותף.

### 2.3 קשת "More" ו-plugins

```
                     ╭─ MORE ARC (opens outward from the NW slot) ─╮
                   ╱  HEIC Pro · TIFF · WebP-lossless · …            ╲
                 ╱    (up to 6 items, centered on the NW direction)    ╲
                         More ⋯   ← hover 250 ms or push outward
```

- **פתיחה:** ‏hover של 250ms על More, או תנועה החוצה דרך הקצה החיצוני שלו.
- **סגירה:** כשחוזרים לטבעת הפנימית או ל-hub.
- **תוכן:** יעדים של plugins מופעלים, לפי הסדר שבהגדרות. לכל היותר 6 ב-v0.1. ההגדרות מראות כמה נשארו מחוץ לקשת.
- **אין plugins פעילים:** More מושבת, ו-hover עליו מציג ב-hub: "No plugins enabled".
- זה עומד בתנאי היציאה של M3: ‏plugin חיצוני מופיע בגלגלת.

| **Processing** | **לא בגלגלת.** אם המשימה לוקחת יותר מכשנייה, מופיע toast במצב "עובד" עם progress. ה-tray מציג badge של עבודה. | toast ו-tray |
| **Done / Error** | toast הצלחה או שגיאה | toast |

### 3.1 Wireframes של הגלגלת

**Armed:** תמונה אחת, PNG. משבצת PNG מושבתת.

```
                              JPG
                    More       │       PNG
                     ⋯   ╲     │     ╱ source        (dimmed)
                           ╲   │   ╱
              ICO ────── ╭──────────╮ ────── WebP
                         │ photo.png│
                         │  1 file  │
              PDF ────── ╰──────────╯ ────── AVIF
                         ╱     │     ╲
                           Compress
```

**Hover על JPG:** ה-hub חוזר על היעד, כי תמונת הגרירה מסתירה את התווית (C5).

```
                         ▓▓▓ JPG ▓▓▓          ← accent fill, pushed out 4 px
                    More   ▓▓▓▓▓▓▓     PNG
                     ⋯   ╲    │      ╱ source
              ICO ────── ╭──────────╮ ────── WebP
                         │  → JPG   │
                         │  1 file  │
              PDF ────── ╰──────────╯ ────── AVIF
                           Compress
                  [drag thumbnail + cursor sit here, over the JPG slot]
```

**ממתין:** ‏DragEnter עוד לא הגיע. בדרך כלל זה נמשך 9–51ms, והמצב מוסתר בתוך אנימציית ההופעה.

```
                              ░░░
                    ░░░        │        ░░░
                         ╲     │     ╱
              ░░░ ────── ╭──────────╮ ────── ░░░
                         │          │      (spinner in hub only if > 150 ms;
                         │    ◌     │       "Can't read this drag" if > 1.5 s, then fade)
              ░░░ ────── ╰──────────╯ ────── ░░░
                              ░░░
```

**לא נתמך:**

```
              (all slots dimmed, no hover highlight)
                         ╭──────────────╮
                         │ ⊘ Not        │
                         │   supported  │
                         │ Folders and  │   other reasons: "Animated images aren't
                         │ zip contents │   supported yet" · "No common format" ·
                         │ aren't…      │   "Not a local file"
                         ╰──────────────╯
              release anywhere = cancel (no-op); the OS cursor shows "no drop"

### 4.1 ‏U1: גלגלת דביקה, טבעת תופסת ודרך חזרה לגרירה רגילה

| התנהגות | ההמלצה |
|---|---|
| Shift משתחרר כשהגלגלת פתוחה | **הגלגלת נשארת פתוחה (דביקה).** ב-spike, שניים מתוך שישה drops קרו אחרי ששחררו את Shift. |
| שחרור בטבעת התופסת (עד 70px מחוץ לדיסקית ב-M) | **ביטול, לא קורה כלום.** אחרת, שחרור כשהסמן קצת מחוץ לדיסקית עם Shift לחוץ היה מעביר את הקובץ ב-Explorer. ⚠️ **זה שינוי לכלל שאושר בשלב 2** ("שחרור מחוץ לגלגלת הולך ל-Explorer"). |
| **דרך חזרה לגרירה רגילה** | **מתרחקים אל מחוץ לטבעת התופסת** (DragLeave). הגלגלת דוהה ונשארת סגורה עד סוף הגרירה, ו-Explorer ממשיך כרגיל. **כדי שהגבול יהיה גלוי:** כשהסמן בתוך הטבעת התופסת, מצויר קו חלש בקצה שלה, באותו חלון ובלי עלות. |

החלופה שנדחתה היא "החזק כדי להציג": הגלגלת נסגרת כשמשחררים Shift, ושחרור מחוץ לגלגלת הולך ל-Explorer. היא פשוטה יותר, אבל מסוכנת יותר: שחרור מוקדם של Shift או החטאה קלה של המשבצת מובילים להעברת הקובץ ב-Explorer.

## 5. ‏Toasts: עיבוד, הצלחה, שגיאה ו-Undo

- **סוג החלון:** חלון Qt משלנו, לא התראה נייטיבית של Windows. כך יש כפתור Undo, עיצוב אחיד, ואין תלות ב-AppUserModelID (U6).
- **מיקום:** הפינה הימנית-התחתונה של המסך שבו היה ה-drop, מעל ה-taskbar.
- **התנהגות:**
  - בלי פוקוס, אבל הכפתורים לחיצים.
  - לכל היותר 3 toasts אחד מעל השני.
  - **הצלחה** נעלמת אחרי 6 שניות, ו-hover עוצר את הספירה.
  - **שגיאה** נעלמת אחרי 12 שניות.
  - **התראה קריטית** לא נעלמת מעצמה.

**עובד** (מעל שנייה, למשל באצווה):

```
╭──────────────────────────────────────────────╮
│ ◌  Converting 12 files to WebP…          ✕   │
│    ▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░  5 / 12              │
╰──────────────────────────────────────────────╯
```

**הצלחה, קובץ אחד:**

```
╭──────────────────────────────────────────────╮
│ ✓  Converted to JPG                       ✕  │

## 7. מראה: Light ו-Dark, צבעים וטיפוגרפיה

- **ערכת צבעים:** ‏Light או Dark לפי המערכת, דרך `QStyleHints.colorScheme()`. הגלגלת מתעדכנת מיד כשהמערכת מחליפה ערכה (`colorSchemeChanged`). ✅ נבדק ב-PySide6 6.12. במחשב הזה: Dark.
- **צבע ההדגשה (accent):** ‏`QPalette.Accent` של המערכת. ✅ במחשב הזה: `#4CC2FF`. ‏WinUI משתמש ב-Light2 של ה-accent במצב Dark, וב-Dark1 במצב Light. ✅
- **אין blur ב-MVP (U5):** לא אימתתי ש-Mica או Acrylic עובדים על חלון עגול עם שקיפות לכל פיקסל. במקום זה, משטח אטום ב-92% עם צל רך. **blur: אחרי MVP, אם יתברר שהוא אפשרי.**

**טוקנים** (מקוד המקור של WinUI, [`Common_themeresources_any.xaml`](https://github.com/microsoft/microsoft-ui-xaml/blob/main/controls/dev/CommonStyles/Common_themeresources_any.xaml), בפורמט `#AARRGGBB` ✅):

| תפקיד | Dark | Light | שימוש אצלנו |
|---|---|---|---|
| רקע בסיס | `#202020` | `#F3F3F3` | הדיסקית (ב-92%) |
| משטח משני | `#2C2C2C` | `#FFFFFF` | משבצת במנוחה, ‏toast |
| טקסט ראשי | `#FFFFFF` | `#E4000000` | תוויות |
| טקסט משני | `#C5FFFFFF` | `#9E000000` | שורת משנה ב-hub |
| טקסט מושבת | `#5DFFFFFF` | `#5C000000` | משבצת מושבתת |
| טקסט על accent | `#000000` | `#FFFFFF` | משבצת ב-hover |
| קו מתאר | `#12FFFFFF` | `#0F000000` | גבולות המשבצות |
| קו מתאר משטח | `#66757575` | `#66757575` | טבעת חיצונית שמפרידה את הדיסקית מרקע כהה |
| קריטי | `#FF99A4`, רקע `#442726` | `#C42B1C`, רקע `#FDE7E9` | שגיאה, התראה קריטית |

- **High Contrast:** צבעי המערכת (`Window`, ‏`WindowText`, ‏`Highlight`, ‏`HighlightedText`). מילוי אטום, גבולות של 2px, ובלי שקיפות וצל.
- **לא רק צבע:** ‏hover מסומן גם בצבע, גם בבליטה החוצה וגם בטקסט ב-hub, בשביל עיוורון צבעים.
- **טיפוגרפיה:** ‏Segoe UI Variable (ובגיבוי Segoe UI). 🔶 לפי ה-type ramp של Windows:

  | רכיב | גודל |
  |---|---|
  | תווית משבצת | 12px Semibold |
  | שורה עליונה ב-hub | 14px Semibold |
  | שורה תחתונה ב-hub | 11px |
  | כותרת toast | 14px Semibold |
  | גוף toast | 12px |

- **אייקונים:** הפורמטים מוצגים כטקסט (JPG, ‏PNG…), כי טקסט ברור יותר מאייקון. ל-Compress, ‏PDF, ‏More ול-Cancel שב-hub יש אייקון קטן מ-Fluent UI System Icons (רישיון MIT 🔶).

## 8. מיקרו-אינטראקציות

משכי הזמן לפי WinUI ([אותו קובץ](https://github.com/microsoft/microsoft-ui-xaml/blob/main/controls/dev/CommonStyles/Common_themeresources_any.xaml)): ‏Faster = 83ms, ‏Fast = 167ms, ‏Normal = 250ms. העקומה: `0,0,0,1` (מהיר בהתחלה, איטי בסוף) ✅.
**כשהאנימציות של Windows כבויות,** כל משך הוא 0, ונשארים רק שינויי הצבע.

| אינטראקציה | מה זז | משך | הערה |
|---|---|---|---|
| הופעת הגלגלת | scale 0.94→1, וכל רכיב עולה מ-opacity 0 | 167ms | **הרצפה וה-hub קולטים מהפריים הראשון (C3)** |
| מילוי המשבצות ב-DragEnter | התוויות מחליפות את השלד ב-crossfade | 83ms | |
| hover על משבצת | צבע accent ובליטה של 4px החוצה | 83ms פנימה, 167ms החוצה | |
| פתיחת קשת More | הקשת גדלה מהקצה הפנימי החוצה | 167ms | |
| drop | הבזק על המשבצת, ואז הגלגלת מתכווצת ל-0.9 ודוהה | 83 + 167ms | החלון לא מאט את Explorer: ה-handler כבר חזר |
| ביטול, יציאה, או שחרור בלי drop | דהייה, ובסוף `hide` | 83ms | מתחילה **מיד** כשהכפתור משתחרר |
| הסמן נכנס לטבעת התופסת | קו חלש בקצה הטבעת | 83ms | מסמן את הגבול של "יציאה לגרירה רגילה" (U1) |
| toast נכנס / יוצא | עולה 12px ודוהה פנימה / דוהה החוצה | 250 / 167ms | |
| progress | פס שמתמלא (כשיש מספר קבצים) או shimmer | – | בלי אנימציות: טקסט "5 / 12" |
| tray במצב עובד | קשת מסתובבת, 8 פריימים | – | בלי אנימציות: נקודה קבועה |

**שקיפות:**
- **הדיסקית:** 92%.
- **הרווחים והטבעת התופסת:** "רצפה" של alpha 1, כלומר בלתי נראים בפועל.
- **מחוץ לחלון:** 0.
- **לעולם לא משתמשים בשקיפות של כל החלון** (C3).
