## Findings

- **The GUI's working set** on the real platform plugin is 125 MB, far above S0's bare-window 57 MB; private bytes are 55 MB. T5a re-baselined the target on private bytes.
- **Pillow's license file omits aom**, the compiled-in AVIF encoder, and **Pillow's generic SBOM lists libimagequant (GPL-3) and FriBiDi (LGPL)**, which the Windows wheel does not link. The texts now ship; a test guards the wheel's codecs (RD-33).
- **The GitHub runner has winget** (not in the image's tool list), older than schema 1.28.0: its `winget validate` succeeds with a warning about the `$schema` header and a non-zero exit. The test tolerates exactly that warning (eab4f38).
- **An intermittent access violation** on the runner killed one CI attempt during a worker respawn in `test_plugin_failures.py`; the rerun was green, and the file passes repeatedly here. Still 🔶 in the tracker.
- **CPython's Windows `LICENSE.txt`** names bzip2 and libffi and carries the Apache text, but not OpenSSL, zlib, Expat, libmpdec or liblzma by name; the notices name them and point to Python's acknowledgements page and, for liblzma, to the 0BSD text in Pillow's file.
