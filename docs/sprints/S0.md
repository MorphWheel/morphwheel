## Findings

1. **Frozen workers load `PySide6.QtCore`.**
   - **Cause:** PyInstaller's `pyi_rth_pyside6` runtime hook runs in every process started from the
     executable, spawned workers included. Our own code imports no Qt in workers: import-linter will
     enforce R2 from S3 on, and the probe confirmed it from source.
   - **Cost:** about 10 MB per worker, and rule R2 is broken in the shipped app.
   - **Proposal for S3:** build a separate **Qt-free worker executable** (`morphwheel-worker.exe`) in
     the same bundle, from its own Analysis that excludes PySide6. Point multiprocessing at it with
     `multiprocessing.set_executable()`. 🔶 Validate with the probe in S3.
   - This is an implementation detail of A5; the approved behavior doesn't change.
2. **No license texts are bundled yet.**
   - The frozen bundle contains Qt 6 (LGPLv3), Python (PSF), OpenSSL 3 (Apache-2.0), Pillow and its
     bundled codec libraries (libavif and others), and the MSVC runtime, but none of their licenses.
   - **S7 must add** `THIRD_PARTY_NOTICES.md` and the license files. Onedir keeps the Qt DLLs
     replaceable, which is what the LGPL needs.
   - pillow-heif / x265 are **not** in the bundle ✅.
3. **Trimmed about 30 MB** without breaking startup:
   - `opengl32sw.dll` (19.7 MB, software OpenGL; raster QWidget painting doesn't use it)
   - Qt's TLS and image-format plugins (Pillow handles images)
   - Qt's own OpenSSL copy
   - The direct2d platform plugin

   Python's OpenSSL stays, because the HEIC download needs HTTPS.

   ⚠ **Corrected 2026-10-19: this was backwards** (RF-1 in `progress.md`). The DLLs that were dropped, `libcrypto-3.dll` and `libssl-3.dll`, are Python's own: the frozen `_ssl.pyd` imports them. The `-3-x64` pair that was kept is the unused one. Fix it in the next session, and check `import ssl` in the frozen app.

   ✅ **Fixed 2026-10-19.** The `-3-x64` pair turned out to be Git for Windows' MinGW OpenSSL, which PyInstaller found on PATH for Qt's TLS backend. The spec now drops that pair, keeps Python's, and fails the build unless Python's pair comes from the interpreter's own `DLLs` folder. In the frozen `measure`, the `tls` check loads OpenSSL 3.0.16 with 62 root certs. The rebuilt bundle is 81 MB.

   ⚠️ The `imageformats` plugins (`qico`, `qsvg`) must come back in S5, when icons land. This is tracked in `progress.md`.
4. Qt proposes **Move under Shift on the `offscreen` platform as well**, so CI's headless tests exercise
   the real hazard.
