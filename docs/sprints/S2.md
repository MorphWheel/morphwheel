## Interpretations and additions (recorded as RD-4 to RD-6)

1. **Inclusive trigger keys** (RD-4). `shift` also matches Ctrl+Shift.
2. **Physical buttons** (RD-5). Raw input and `GetAsyncKeyState` name physical buttons, so swapped buttons are honored through `SM_SWAPBUTTON`.
3. **"Restart normally"** (RD-6). Implemented with the shell's token. "Elevated" is the full half of a split token, so UAC-off machines are not warned (they would otherwise restart in a loop).
4. **Ticks.** Qt sends no DragMove while the pointer and keys are still, so the session's dwell, spinner and give-up timers advance on the poller's `sampled` signal. The window has no timer of its own.
5. **Queued wheel signals.** `dropEvent` does only the decision and the emit. Hiding, logging and (in S3) the job start run after OLE's `Drop` has returned.
6. **DragLeave is classified by the controller** from the primary button's state: left the halo (button down) or released over the hub (button up).
7. **A rejected Drop emits `cancelled`.** OLE sends Drop, not DragLeave, when the last DragMove was accepted; the machine hides at once instead of waiting for the grace period.
8. **Qt routes a Drop only after an accepted DragEnter** (found while testing). One more reason DragEnter is always accepted.

## Findings

1. **`Signal(int)` is a 32-bit C int.** A nanosecond timestamp overflows it; the real-timer test caught it. Ticks travel as a Python object.
2. **A key held across gestures never reopened the wheel** (code review). The poller was already running during the release grace, so a new press didn't reset it. Fixed and tested.
3. **The drag threshold doesn't scale with DPI on this machine:** `GetSystemMetricsForDpi(SM_CXDRAG)` is 4 at 96, 120, 144 and 192 DPI. The code asks per DPI anyway; the tests only assert it is positive.
4. **Client-area animation reads as off over RDP**, which matches the user's environment and gives a real negative control for C7.
5. **Esc reaches the wheel as a DragLeave with the button still down** (C18), so it is handled as "left the halo": the wheel hides, the gesture is dismissed, and the raw mouse-up ends it. The checklist row says so now.
6. **The code review's skipped item:** `dev_catalog()` duplicates `tests/unit/builtin_targets.py`. Both go away when S3's manifest arrives.
